# 🛒 Supermarket Sales Dashboard

This Power BI dashboard provides an analytical report for supermarket sales data. The report helps in understanding sales performance, customer behavior, and product trends.

## 📊 Dashboard Features

- **Sales Overview**: Total revenue, average sales per transaction, and sales trend over time.
- **Customer Analysis**: Breakdown by gender, city, and customer type.
- **Product Insights**: Top-performing product lines, quantity sold, and gross income.
- **Time-based Analysis**: Insights by day of the week and time of day.
